# MY SUZU ROAD BOOK（プロトタイプ）

石川県珠洲市を舞台にした、観光・関係人口アプリの試作。
**現時点で何が作れるか、どこで詰まるかを知るためのもの**で、実利用を想定したものではない。

> **これは珠洲市の公式サービスではありません。**
> 個人が検証のために作ったプロトタイプです。掲載内容は正確でない場合があります。

- 作成：2026-10-31

## 動かし方

このフォルダの **`起動.cmd` をダブルクリック**する。

※ `serve.ps1` をダブルクリックしてはいけない。`.ps1` は実行用の関連付けがないため「アプリの選択」が出る。**何も選ばずキャンセル**すること（選ぶと次回から勝手にエディタで開くようになる）。

PowerShell から直接動かす場合はこちら。

```powershell
powershell -ExecutionPolicy Bypass -File ".\serve.ps1"
```

起動すると、このPC用とスマホ用のURLが表示される。終了は `Ctrl + C`。

### 位置情報（GPS）を実機で試すとき

**`起動_HTTPS.cmd` をダブルクリック**する。位置情報APIはHTTPSでないと動かないため、
こちらは自己署名の証明書を作って **HTTPS（ポート443）** で配信する。openssl は Git for Windows 同梱のものを使う。追加インストールは不要。

起動すると **QRコードのページが自動で開く**。スマホのカメラで読めばアドレスを打たなくて済む。

| 見る端末 | URL |
|---|---|
| このPC | `https://localhost/` |
| 同じWi-Fiのスマホ | `https://<表示されたIP>/`（ポート番号なし） |

**ポート番号を付けないで開ける**ようにしてある。443はHTTPSの標準ポートのため。
あわせてポート80でも待ち受け、HTTPで来たものはHTTPSへ送り返す。
`192.168.x.x` と打つだけでも、`http://` で来ても、必ずアプリにたどり着く。
443・80がふさがっていたときは 8443・8080 に落ちる（そのときは表示されたURLに従う）。

**スマホでは「安全ではありません」という警告が出る。** このPCが自分で発行した証明書のため。
詳細を開いてそのままアクセスし、位置情報の利用を「許可」する。
※iOSでの警告画面の流れは未確認。

証明書は `.cert/` に作られ、PCのIPが変わったときだけ作り直される。
QRのページ `qr.html` は起動のたびに作り直される（gitignore 済み）。

| 見る端末 | URL |
|---|---|
| このPC | `http://localhost:8000/` |
| 同じWi-Fiのスマホ | `http://<表示されたIP>:8000/` |

必要なもの：Python 3（`python -m http.server` を使うだけ）、インターネット接続（地図タイルとLeafletの読み込み）。

**同じWi-Fi内に配るとき、フォルダはまるごと公開されない。**
先頭が「.」で始まる階層（`.cert/` の秘密鍵、`.git/` など）は配信しない（`safe_server.py`）。
`python -m http.server` をそのまま使うと秘密鍵まで読めてしまうため、使っていない。

**初回はWindowsファイアウォールの確認が出ることがある。** スマホから見るには「プライベートネットワーク」を許可する。許可しても、このPCのこのフォルダを同じWi-Fi内に公開するだけで、インターネットには出ない。スマホで開けないときはここを疑う。

### URLの末尾に付けられるもの（検証用）

| パラメータ | 動作 |
|---|---|
| `?mock=1` | 最初から擬似位置モードで開く |
| `?seed=1` | 4か所を訪問済みにした状態から始める（埋まった地図を見たいとき） |
| `?fresh=1` | **保存済みのキャッシュを捨てて読み直す**（直したものが出てこないとき） |

例：`http://localhost:8000/?mock=1&seed=1`

### 直したものが実機に出てこないとき

**画面の右上に版（`v7` など）が出る。**ここが上がっていなければ、古いものを開いている。

1. **ページを読み込み直す**。ホーム画面から開いている場合は、アプリ切替画面から一度終了して開き直す
2. それでも変わらなければ、URLの末尾に **`?fresh=1`** を付けて開く。
   サービスワーカーと保存済みキャッシュを捨てて読み直す。**訪問の記録と写真は消えない**

サービスワーカーは**通信があるときは必ず新しいものを取りに行く**ようにしてある（v7以降）。
取れないときだけキャッシュを使うので、オフライン対応は効いたまま。
写真とアイコンは中身が変わらないので、これまでどおりキャッシュを先に返す。

## 位置情報について（重要）

**Geolocation API は HTTPS でないと動かない**（`localhost` だけが例外）。
スマホから `http://192.168.x.x:8000/` で開くと画面は普通に出るが、位置は取得できない。

そのため、位置の扱いを二段構えにしてある。

- **GPSが使える場合** — 実際の現在地を使う
- **使えない場合** — 自動で**擬似位置モード**になり、**地図をタップした場所が現在地**になる

左上の状態表示をタップすると、手動で切り替えられる。
また、GPSで取れた現在地が珠洲市から60km以上離れている場合は、自動で擬似位置モードに切り替わる（PCの位置情報は市外を返すことが多いため）。

## 操作

**起動画面**

開くと霧がかかっていて、流れて晴れると珠洲（聖域の岬）が現れ、ロゴが組み上がる。約2.6秒。
**画面のどこを押してもとばせる**。記録があるときはボタンが「つづきから」になる。

動き自体は CSS の transition と遅延だけで組んである（JSは合図と中断のみ）。
キーフレームではなく遅延つきの transition なのは、とばすときに遅延を0にするだけで最後の姿へ送れるため。
端末の「視差効果を減らす」設定が入っているときは、最初から最後の姿で出す。

画面は **MAP／BOOK／GACHA／GARAGE** の4つ。
各画面の見出しには珠洲の景色を敷いてある（資料の雰囲気に寄せるため）。
ただし**手元の写真はWikimediaのCC画像**で、資料の生成画像のような派手さはない。印象の差はここから来る。

**MAP**
1. 地図は霧に覆われている。訪問済みの場所と現在地のまわりだけが晴れる
2. 左上に**探索率**（訪れたスポット数）が出る
3. 近くにスポットがあると下に詳細が出る。**300m以内に入るとチェックインできる**
   - **「行き方」**で地図アプリ（Googleマップ）のルート案内が開く。出発地は渡さず、端末の現在地に任せる
4. 近くに何もなければ**「次の発見」**が出る。押すとその場所へ地図が動く
5. チェックイン後、**「写真を撮る」**でカメラが起動する（HTTPでも動く）
6. 撮った写真はピンになる。**「写真を削除」**で元の紹介写真に戻る

**BOOK（珠洲図鑑）**
- カテゴリ（観光・グルメ・特産・文化・祭り）で絞り込める
- 未発見は鍵がかかって見えない。**ガチャで知ったものは写真と名前が見え、「未訪問」が付く**
- **知っているものはカードを押せる**。押すと地図へ飛んで詳細が出るので、そこから行き方を調べられる
- 一番下に**「記録を書き出す」「記録を読み込む」**。JSONファイル1本になるので、クラウドドライブ等に置けば別の端末で戻せる

**GACHA（SUZU GACHA）**
- スポットに**初めてチェックインするとコイン3枚**
- コイン1枚で**まだ知らないスポットを1つ開放**できる。地図に**写真つきのピン**で出て、図鑑でも写真と名前が見えるようになる
- ただし**訪問済みにはならない**。図鑑を埋めるには現地でチェックインが必要
- 回すと**画面いっぱいの霧の向こうで光が強まり、渦を巻いて晴れると、当たったスポットの写真が現れる**（約2.5〜4秒、タップでとばせる）
- GACHAタブの下に**「まだ見ぬ珠洲」**＝未発見スポットの写真をぼかして並べてある
- **レア度**はスポットの種類で決まる。★★★激レア＝祭り・文化／★★レア＝特産・グルメ／★ノーマル＝観光。
  レアなものほど光っている時間が長く、光の色も変わる（青→緑→金）

**GARAGE**
- **登録ナンバー**。希望の数字を入れて**「この番号で登録する」**を押すと、
  まだ使われていないひらがなが付いて、**利用者ごとに重複しない番号**になる（`あ・・61`）
  - 形は本物のナンバープレートに合わせてある。**ひらがな1字 ＋ 1〜9999 の数字**。
    4桁に満たないぶんは中点で埋まり、**先頭の0は詰まる**（`0115`→`・115`）。
    ひらがなは**あ〜わ から お・し・へ・ん を除いた41字**で、尽きたら A〜Z。約67万通り
  - 未入力のときは **`・・・・` だけ**が出る（入力例は置かない。番号が入っているように見えてしまうため）
  - 上段は本物の分類番号にあたる行。ここには**訪れたスポット数**が入る（`珠洲 04`）
  - 重複の確認だけを外の窓口（`api/`）に置いている。**氏名も連絡先も送らない**。
    つながらないときは、番号は端末の中だけの飾りとして今までどおり使える
  - 一緒に受け取る**再発行キー**は、端末を変えたときに番号を取り戻すためのもので、
    「記録を書き出す」のファイルに含まれる
- **TOURING BADGE** は BRONZE（3スポット）／SILVER（6）／GOLD（10）で解放。
  **SVGで描いている**（金属の縁・弧を描くSUZU NOTO・海岸線と灯台・ナンバープレート・リボン）。
  未獲得は色を抜いた状態で並ぶので、**何が待っているかは見える**
- **「画像にして共有」** で、いま持っているいちばん上のバッジを**1080×1080のPNG**にする。
  共有シートが使える端末では共有シートが開き、使えない端末では画像が保存される
- 走った記録（訪問数・写真数・残り）
- 一番下に**出口導線「つながる」**。押すと**「準備中です」の仮画面**が出る（遷移先の電子申請システムが未確定のため）

地図右上の**「霧を晴らす」「記録を消す」は検証用**。製品に残すものではない。

記録は **この端末の中だけ**に保存される。サーバーへ送信するものは何もない。
内訳は、どこへいつ行ったかが localStorage、**写真の実体は IndexedDB**。記録は写真のIDだけを持ち、実体はIDで引く。


## ホーム画面に追加する（PWA）

iOS Safari には、**7日間アクセスがないと端末内の保存データを消す仕組み**がある（ITP）。
**ホーム画面に追加すると対象外**とされるため、記録を守るうえで重要になる。あわせてオフラインでも開けるようになる。

**iOSには「ホーム画面に追加」を自動で行うAPIがない。** アプリ側からできるのは案内を出すところまでで、最後は利用者の操作が必要。

BOOKタブの一番下に、いま効いているかどうかが出る。

```
オフライン：対応あり（24件を保存済み）　ホーム画面：未追加
```
別の端末・別のブラウザで開けば、記録はゼロから。

### 写真素材

8件は **Wikimedia Commons の CC / CC0 画像**。出典・作者・ライセンスは `img/credits.json` に記録してある。
**CCライセンスはクレジット表記が条件**なので、公開版ではアプリ内に表示が必要。

2件（**道の駅すずなり・木ノ浦海岸**）は適切な画像がなく、**名前を入れた仮画像を生成**して当ててある。見れば仮だと分かる。

## 既知の制約（プロトタイプとして割り切った点）

- **緯度経度はおおよその値**。チェックイン判定に直結するので、実運用では現地実測か公式データが必要。**「行き方」の目的地もこの座標**なので、着く場所も多少ずれる
- **iOS Safari の7日ルール（ITP）**。7日間アクセスがないと、端末内の保存データが消える可能性がある。**ホーム画面に追加すれば対象外**とされるが、未検証。これが書き出し機能を置いた理由
- **オフライン対応はHTTPSでしか効かない**。サービスワーカーの制約。LAN内のHTTPでスマホから開いた場合、画面は出るがオフラインでは開けない
- **Cache Storageが使えない環境がある**（プライベートブラウズ、容量逼迫など）。その場合もアプリは動くが、オフラインでは開けない。BOOKタブ下部の状態表示で実際に効いているか確認できる
- **近接スポットのピンが重なる**（蛸島町周辺）。広域表示では名前を隠して逃げている
- **グルメのスポットがない**。カテゴリは用意したが、該当する素材（店・料理の写真と紹介文）が手元になく0件。観光交流課の素材が要る
- **未検証**：実機カメラの挙動、実GPSの精度と電池消費、トンネル・山間部での測位、オフライン時の動作
- **自己署名の証明書では、iOSでサービスワーカーが登録できない可能性がある**（証明書エラーを承認したオリジンでは登録を拒むブラウザがある）。位置情報は試せても、オフライン動作は別の手段での確認が要るかもしれない
- **レア度の割り当ては仮**。祭り・文化を激レアにしてあるが、何をレアにするかで人の動きが変わる。素材が増えたら見直しが要る
- **バッジの絵は手描きのSVG**。形は資料に寄せたが、生成画像のような階調・光沢は出ない。素材が用意できたら差し替えになる（`badge.js` の `SKIN` が段ごとの色）
- **共有が実機で成立するかは未検証**。iOS Safari は `navigator.share` を利用者の操作と同じ流れで呼ばないと断ることがあるため、画面を描いた時点で画像を先に作ってある。それでも断られたときは保存に切り替わる
- **登録ナンバーは重複する**。4桁なので1万通りしかない。一意のIDとして使うなら発行の管理が要り、そこでサーバーと個人情報の話になる。いまは「自分で決める飾り」として置いてある
- **番号を持つのは「人」ではなく「端末」**。ログインがないため、再発行キーを失うと取り戻せず、
  その番号は埋まったまま残る。「別の番号にする」でも前の番号は返らない
- **同時に確保すると、まれに同じ文字が2人に出る可能性がある**（KVの反映に時間差があるため）
- ROAD PLATE、WOOD TAG は**入れていない**。関係人口への出口導線は**仮画面（準備中）**まで
