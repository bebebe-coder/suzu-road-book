# 登録ナンバーの窓口（Cloudflare Workers）

アプリの登録ナンバーを、利用者ごとに重複しないものにするための窓口。

**持っているのは「その5桁が使われているか」だけ。** 氏名も連絡先も扱わない。

- 本体：`https://suzu-plate.bebebe-coder.workers.dev`
- 保管庫：Workers KV（名前空間 `PLATES`）

## 番号の形

本物のナンバープレートに合わせてある。

```
あ・・61     ← ひらがな1字 ＋ 1〜9999 の数字（4桁に満たないぶんは中点）
```

| 位置 | 中身 | 通り数 |
|---|---|---|
| 1文字目 | ひらがな。**あ〜わ から お・し・へ・ん を除いた41字**。尽きたら A〜Z | 67 |
| 2〜5文字目 | 1〜9999 の数字。**先頭の0は詰める**（本物に `0115` は無く、`115` は `・115` と出る） | 9,999 |

組み合わせは **約67万通り**。希望の数字を出すと、まだ使われていない文字が自動で付く。

## 窓口

いずれも `Origin` が許可されたサイトでないと 403。

| | 内容 |
|---|---|
| `GET /v1/check?n=61` | 空いている最初の文字を返す（読み取りのみ） |
| `POST /v1/claim` `{"n":"61"}` | 確保して、番号と**再発行キー**を返す |
| `POST /v1/verify` `{"n","mark","key"}` | その番号が本人のものか確かめる |

再発行キーは**そのまま保管しない**。SHA-256 にしてから置いている。

## 無料枠に合わせた作り

KVの無料枠は**読み取り10万回／日に対し、書き込みは1,000回／日**しかない。そのため、

- **空き確認は読み取りだけ**で済ませる。書き込むのは確保する瞬間だけ
- 空き探しで67回読まないよう、使用済みの文字を `idx:<数字>` に**1つの文字列でまとめて1回で読む**

荒らし対策は Cloudflare 側の仕組み（1つのIPから1分20回まで）。
KVで回数を数えると書き込み枠を食い潰すため。

## 動かし方

```powershell
npx wrangler deploy          # 公開
npx wrangler tail            # ログを見る
npx wrangler kv key list --binding PLATES --remote   # 中身を見る
```

## 割り切った点

- **番号を持つのは「人」ではなく「端末」。** ログインがないため、再発行キーを失うと取り戻せず、
  その番号は埋まったまま残る。キーは記録の書き出し（JSON）に含まれる
- **「別の番号にする」と、前の番号は埋まったまま。** 返却の窓口を作っていない
- **同時に確保すると、まれに同じ文字が2人に出る可能性がある。** KVは書き込みの反映に時間差があるため。
  厳密にするには Durable Objects が要る
- **アクセス元のIPはCloudflare側に記録される。** 市の制作物にする段階では、
  外部サービス利用（情報セキュリティポリシー 8.3／8.4）の判断対象になる
